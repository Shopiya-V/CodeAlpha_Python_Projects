CodeAlpha Python Projects

This repository contains three Python projects completed as part of my CodeAlpha learning journey.

Task 1: Hangman Game
- A word-guessing game.
- Uses random word selection.
- Tracks correct and incorrect guesses.
- Displays win or lose messages.

Technology: Python

Task 2: Stock Portfolio Tracker
- Add stock names, prices, and quantities.
- Calculate the total stock value.
- View the portfolio.
- Exit the application.

Technology: Python

Task 3: Task Automation - File Organizer
- Organizes files based on their extensions.
- Creates separate folders automatically.
- Moves files into their respective folders.

Technology: Python (`os`, `shutil`)

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the required task folder in VS Code.
4. Run the corresponding Python file.
